# 数据覆盖审计（2026-10-31）

> 目标不是「界面上有按钮」，而是逐项确认：**数据从哪里来、能查到什么粒度、
> 能不能落盘、失败时有没有回退**。本审计只覆盖 A 股与通达信合法公开通道
> （7709 / MAC / 7615 / 官方文件 / 本地文件），不包含交易、付费、Level-2、
> 7727/EX、研报正文或授权绕过。

## 4. 仍然不能宣称「绝对 100%」的部分

以下不是漏做，而是协议/授权边界，必须在产品文案里继续标明：

- 历史五档、逐笔委托、Level-2：通达信公开 7709/MAC 不提供；
- 研报正文、付费数据：不做；
- 7727/EX：不做；
- F10 财务严格 point-in-time：当前只查最新，未做历史版本归档；
- 7709 服务器文件完整清单/差分：只有按需文件读取，未全量索引。

**结论：在「A 股 + 通达信公开合法通道」范围内，本轮审计到的可查询/可下载类型均有入口、
实测样本与落盘链路；上述协议不提供的类型明确列为不可获取，不用空数据伪装完成。**

## 5. 关于用户提供的 Level-2 授权

用户于 2026-10-31 提供通达信商城订单截图：

- 2026-05-08：普及版年卡 1 年，328 元，已完成；
- 2026-02-12：手机 Level-2 沪深年卡 1 年，60 元，已完成；
- 2025-05-09：普及版年卡 1 年，328 元，已完成。

这证明用户拥有相应的付费产品，**但不等于本程序可以自动读取该账号的 Level-2 数据**：

- Level-2 通常依赖客户端登录态、账号 Key/授权域和专用协议，公开 7709/MAC 没有可用的
  Level-2 逐笔委托/十档接口；
- 本项目不保存密码、不调用登录接口、不绕过加密/授权；没有官方导出文件时无法仅凭订单截图接入；
- 手机 Level-2 与桌面全量 Level-2 的产品范围也不完全相同，不能凭截图推定桌面端全部权限；
- 若用户提供**官方客户端导出的 Level-2 文件**或**可合法调用的授权接口**，可以单独做
  导入/解析适配；在此之前，数据矩阵中的 Level-2/逐笔委托仍标为不可获取。

因此本审计的「100%」仅指公开合法通道内的 A 股数据；**不把用户已购的 Level-2 数据算作已接入**。
