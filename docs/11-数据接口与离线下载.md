# 数据接口与离线下载

> 目标：把通达信可合法读取的 A 股数据尽量完整地落成**可追溯、可重放**的本地数据，
> 供 Python/机器学习使用。交易下单、付费授权数据、7727/EX 不在范围内。

## 1. 运行时通道

| 通道 | 地址 | 用途 | 当前状态 |
| --- | --- | --- | --- |
| 7709 行情主站 | TCP 7709 | 代码表、快照、K 线、分时/五日、逐笔、竞价、财务、F10 文本、服务器文件 | 已接 19 个命令；仍有部分字段/历史范围未覆盖 |
| MAC | TCP 7709 | 全市场快照、异动、板块、资金流 | 已接；部分排行/推送字段受限 |
| 7615 TQLEX | HTTP 7615 | 公告、F10 在线资料、行业、报表、交易数据 | 已接 F10 19 页签 |
| 本地文件 | `.day/.lc1/.lc5/.5` | 离线行情读取、CSV、写回、SQLite | 已接 |

## 2. 当前可下载的数据

| 数据 | 入口 | 落盘位置 |
| --- | --- | --- |
| 官方 `zhb.zip` | 数据工具 → 下载摘要 / 规范化导出 | `raw/tdx/`、`normalized/tdx/zhb_stats/` |
| tdxstat | 数据工具 → 导出 CSV/Parquet/SQLite | `normalized/...` |

| 设置/持仓 | 设置导出、组合分析导出 | 用户下载目录 |

## 3. 已实现的读取/回退链路

- K 线请求成功：写 `cache/klines/<code>_<period>_<count>_<adjust>.json`；
- 请求失败：自动读同一 key 的缓存，返回 `source=cache`；
- 图表头显示「离线缓存」，不把缓存伪装成实时；
- 缓存显式预热：数据工具「离线 K 线缓存」为当前自选股拉 800 根前复权日 K；
- 本地数据清单：数据工具「本地离线数据」扫描 raw/cache/lake/exports/normalized/local。

## 4. 仍然缺的接口（不宣称已做全）

以下缺口按优先级排列，后续需要单独实现并保留真实报文/schema：

1. 全市场历史日 K 批量下载（当前只有自选批量导出/缓存，不是 5,615 只全量）；
2. 历史分时、历史五日、历史逐笔分页的批量落盘；
3. 集合竞价历史（当前服务端只返回当日）；
4. 财务/公告的严格 point-in-time 全量快照；
5. 7709 文件下载的完整清单与差分更新；
6. 0x0547 等真实推送通道（当前服务端能力/字段未完全验证）；
7. 研报正文（授权边界，明确不做）。

## 5. 机器学习数据约定

- 原始层不可变；
- 规范层按 `trade_date` 分区，使用 Parquet + schema 版本；
- 每条数据保留来源、抓取时间、解析器版本、校验和；
- 财务/公告使用公告日/报告期，避免未来函数；
- 退市、停牌、ST 保留，不静默过滤。
