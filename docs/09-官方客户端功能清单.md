# 09 · 官方客户端功能清单（A 股免费功能）

> **用途**：这是「对齐通达信官方客户端」的**唯一功能基线**。P0 产出，
> 后续每一项实现、截图、验收都以本表为准；没有表内状态更新，不算完成。
>
> **边界**：只覆盖 A 股**免费**行情 / 分析 / 选股 / 资料 / 数据管理功能。
> 交易下单、Level-2、付费授权数据单列，不通过逆向或破解实现。
>
> **证据原则**：✅ 必须有代码 + 测试/截图；🟡 只能写「部分」并说明缺什么；
> ⬜ 是计划；⛔ 是非目标或需授权。**不把计划写成现状。**
>
> 官方客户端参照：Linux V7.64（2022 构建）+ Windows V7.73（2026-09）配置；
> 界面行为以实机截图/操作为准，不复制其闭源资源。
