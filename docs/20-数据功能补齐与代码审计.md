## 2. eltdx / gotdx 吃透程度

| 项目 | 读了多少 | 结论 |
| --- | --- | --- |

| eltdx MAC | 17 条命令表、位图/字段、文件/离线 | 14 条可用 + 1217 空分片；EX 2 条不做；docs/19 |
| eltdx 7615 | client.py 159 方法、A 股约 70、84 频道 | 19 页签 + 7 Entry + 7 HQServ + 20 行业子页 + 84 频道 |

| eltdx 运行时 | Rust pool/deadline/generation | 帧上限/deadline/push 清空已做；generation 未做 |
| gotdx 全部 | 185 go 文件、协议/连接池/订阅 | 协议差异清单 docs/16；推送事实修正；MAC 10 条新增移植 |
| gotdx 未读部分 | `cache/`（Redis 缓存）、`examples/` 大部分 | 与 A 股数据能力无关；不引入 Redis |

**对照方法（可复核）**：

- eltdx Rust 的 `TYPE_*` 共 26 个，与 pythontdx 的 `CMD_*` 26 个一一对应；
  pythontdx 另有 0x051a/0x053f/0x0563 三个扩展。
- eltdx `MacClient` 的 17 条命令中 A 股相关 15 条，pythontdx 15 条全部实现；
  0x254D/0x2562 属 EX，不做。
- eltdx `f10/client.py` 有 157 个方法，包含 `mg_/gz_/qyz_/...` 非 A 股与大量
  section 包装；pythontdx 用 51 个 `fetch_*` + `MARKET_REPORT_SECTIONS` 覆盖
  A 股语义。`index_members/index_etfs/ipo_calendar` 已用别名映射到现有
  `index_flow_members/index_tracking/market_new_shares`。
- gotdx 185 个 Go 文件中与 A 股协议相关的是 `proto/mac_*`、`proto/*` 命令与
  连接池/订阅；已吸收 0x1215 元信息/0x1217 分片解析、160 位位图、轮询推送语义
  （0x1217 实测空分片，未宣称可用）。

**结论**：A 股相关协议与可落地的技术已逐条对照；未落地项均为「许可/体积/收益/EX 边界」
明确列出的，不是漏读。

## 3. 仍未做全的项（如实列出）

   `timeRaw/currentHand/openAmount/recordHex` 已保留。serverTime 语义未确认。
2. **MAC 0x1217**：命令与解析已实现，但测试主机返回空分片（0x1215 元信息正常）；
   生产文件下载仍以 0x06b9 为准。
3. **逐笔 recordHex / K 线 recordHex**；0x0fc6 已返回 priceBase、0x044d 已补扩展字段。
4. **运行时 generation**（重连代际）与 retry-safe 的「发送完成」标记。

GBBQ（本机 202,313 条）与 7615 涨跌停梯子（131 行）已在 2026-11-04 补齐并验证。
GBBQ 的 `market=2` 同时包含北交所与新三板（本机 14,608 条，430/83/87/92 开头），
当前统一标 `bj`；做 A 股池时需按代码段再过滤，不能只信市场号。

以上不是「忘了」，而是按数据价值/许可/体积/EX 边界排序后的剩余项；需要时按
docs/17 §8.2 的顺序继续。

### 4.1 已修复（本轮自查）

- **TQLEX_URL 覆盖失效**：`_post_tqlex` 改用多主机后忽略测试/部署注入的
  `TQLEX_URL`，`test_ignores_http_proxy` 直接打到真实主机返回 503。修复：把
  `TQLEX_URL` 放在候选首位再去重；测试恢复通过。
- **MAC 多日分时不裁剪**：`fetch_tick_charts(days=1)` 返回 2 天；修复为把 `days`
  传入 parser 并裁剪。
- **MAC K 线丢首根**：`0x122E` 首条被当昨收基准丢弃，全历史少最老一根；修复为
  `keep_first=True` + 跨页 `pre_close_hint`，实测 6035 根（与 7709 一致）。
- **gpcw 空占位包**：`gpcw20261231.zip`（164B）会解析失败；离线任务过滤未来报告期
  与 <1KB 空包，实测 5,572 行成功。
- **ColDes 列名**：HQServ 结果集 ColName 为空、ColDes 是 `{"Name":...}` 时列名丢失；
  已回退解析并给重复列加 `__2`。
- **节假日 worker 误暂停**：manager 用 `offline_window`（含节假日表），worker 却只按
  周末判断，节假日会「允许启动后立刻暂停」；worker 改为复用 `offline_window`（30s 缓存）。
- **worker 全崩却报 completed**：增加 returncode / worker summary 状态检查，
  全异常时状态为 `failed` 并写 `error`。
- **MAC 单只快照越界**：汇总段阈值按 109 判断却读到 +120，短报文会抛 struct.error；
  改为 120。
- **MAC 全历史 offset 上限**：0x122E 的 start 是 u32，循环却按 0xFFFF 截断；
  改为 u32 + max_pages 400（5 秒线需要）。
- **HQServ 双重解析**：`fetch_hq_nlp` 对同一结果集解析两次，改为一次。
